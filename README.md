# SubmittalBook

A browser-accessible application for managing submittal documents.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gabeslivka/SubmittalBook.git
   cd SubmittalBook
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

Start the development server:

```bash
npm start
```

The application will be available at [http://localhost:3000](http://localhost:3000)

## Features

- Dashboard view with recent submittals
- Status tracking (Pending, Approved, Under Review)
- Responsive design for desktop and mobile
- Quick action buttons for common tasks
